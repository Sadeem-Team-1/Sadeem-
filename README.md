# ☁️ منصة تيم سديم التعليمية — SADEEM TEAM Platform

موقع تعليمي متكامل لطلاب الكلية: بنك ملخصات ومحاضرات (Google Drive) + بوت ذكي يجيب على أسئلة الطلاب + لوحة تحكم كاملة للمشرفين + إعلانات فورية — كل حاجة جوه الموقع.

مبني بـ **HTML + Tailwind CSS + JavaScript خالص** — بدون أي إطار عمل أو خطوة بناء (Build)، جاهز للرفع مباشرة على **GitHub Pages** أو أي استضافة ثابتة.

---

## 📦 نسختان جاهزتان للتحميل

| النسخة | المحتوى | امتى تستخدمها |
|---|---|---|
| **الملف الواحد** (`sadeem-one-file.zip`) | ملف `index.html` واحد فيه كل شيء — الواجهة + البوت + لوحة التحكم (تُفتح بـ `#/admin` في آخر الرابط) | أسرع طريقة للرفع على GitHub: ملف واحد وتخلص. مفيش مجلدات تتبعت ولا مسارات تتبوّظ |
| **النسخة الكاملة** (المجلد ده) | ملفات منفصلة منظمة (`css/` · `js/` · `assets/`) + دليل `FIREBASE_SETUP.html` المصوّر | لو هتعدّل الكود كتير أو تشتغل بمطورين |

> ⚠️ **أهم نصيحة للرفع على GitHub (سبب 90% من المشاكل):**
> GitHub **ما بيفكش الضغط** — لو رفعت ملف الـ zip نفسه الموقع مش هيشتغل.
> الصح: فك الضغط الأول، وبعدين ارفع **الملفات اللي جوه المجلد** (مش المجلد نفسه).
> في نسخة الملف الواحد المشكلة دي مش موجودة أصلاً — ملف واحد ودّوس Done.

## ✨ المميزات

### واجهة الطلاب (`index.html`)
- شريط إعلانات متحرك (Ticker) يعرض الإعلانات المعتمدة فوراً، والعاجل بلون أحمر مميز.
- شريط بحث ذكي: يبحث في المواد والملخصات والأسئلة الشائعة مع نتائج مصنّفة والانتقال السلس.
- بنك الملخصات: بطاقات مواد مع ملفات (محاضرة / ملخص / سكشن / شيت / تطبيق) وزر «فتح الرابط» لـ Google Drive + فلاتر بالأنواع.
- **بوت سديم 🤖**: ويدجت محادثة جوه الموقع — يرد فوراً من الأسئلة الشائعة وبنك الملخصات والإعلانات، وعند سؤال جديد كلياً يرفعه لنظام الأسئلة الواردة للفريق (مع دمج الأسئلة المتكررة تلقائياً).
- **زر «اسأل سؤال» 💬**: الطالب يكتب سؤاله في نموذج بسيط — يُسجَّل فوراً بنظام الأسئلة الواردة ويترد عليه الفريق من لوحة التحكم. الأسئلة الرسمية كلها جوه الموقع.
- **إشعار رد الفريق 🔔**: أول ما الأدمن يعتمد إجابة سؤال الطالب، يظهر للطالب شريط أخضر في أعلى الصفحة الرئيسية «فريق سديم رد على سؤالك!» مع زر «شوف الإجابة» يفتح الرد مباشرة. (في وضع Firebase الإشعار يوصل عبر الأجهزة، وفي الوضع المحلي يشتغل على نفس المتصفح).
- **ردود مثبتة في الرئيسية 📌**: عند الاعتماد، الأدمن يختار «ثبّتيها في الصفحة الرئيسية لكل الطلاب» — فتظهر كبطاقة في قسم «أسئلة طلاب والفريق ردّ عليها» فوق بنك الملخصات، والتثبيت قابل للإلغاء من لوحة التحكم في أي وقت.
- **مجتمع الواتساب 💚 (اختياري)**: زر أخضر عائم — مخفي حالياً لأن المجتمع مقفول. لو رجع المجتمع، حط الرابط من لوحة التحكم ← الإعدادات وهو هيظهر تلقائياً. الأسئلة الرسمية كلها جوه الموقع.
- أسئلة شائعة (أكورديون) تتحدث مباشرة بعد اعتماد المشرف أي إجابة.
- واجهة متجاوبة بالكامل (هاتف / تابلت / كمبيوتر) ويدعم RTL بالكامل.

### لوحة تحكم المشرفين (`admin.html`)
- تسجيل دخول بطريقتين: **البريد وكلمة المرور** أو **كود التيم السريع**، مع قفل مؤقت بعد 5 محاولات فاشلة.
- **الأسئلة الواردة**: كل سؤال يجيلنا من الطلاب (سديم بوت أو زر «اسأل سؤال») يوصل هنا مع زر [اعتماد الإجابة ونشرها] → يتحول فوراً إلى سؤال شائع على واجهة الطلاب. مع فلاتر (بانتظار الاعتماد / معتمدة / متجاهلة) وعدّاد تكرار السؤال.
- **إدارة الملخصات**: إضافة / تعديل / حذف المواد وملفات Drive مباشرة من الموقع — بدون كود وبدون GitHub.
- **الإعلانات (Broadcast)**: كتابة خبر عاجل أو موعد امتحان → يظهر فوراً في شريط الطلاب، مع تشغيل/إيقاف وتعديل وحذف.
- **الإعدادات**: بيانات الدخول وكود التيم، رابط واتساب اختياري (سيبه فاضي = الزر مخفي نهائياً)، تصدير/استيراد نسخة احتياطية JSON، واستعادة البيانات الافتراضية.

## 📤 النشر على GitHub Pages (خطوة بخطوة)

1. فك ضغط الملف (لو نزّلت الـ zip) — المهم إنك تشوف الملفات نفسها (`index.html` وغيره).
2. أنشئ مستودعاً جديداً على GitHub (مثلاً `sadeem-platform`) — Public.
3. في صفحة المستودع اضغط لينك **«uploading an existing file»** (أو Add file ← Upload files).
4. اسحب **كل الملفات اللي جوه المجلد** (مش المجلد نفسه ولا الـ zip) وارميهم في منطقة الرفع ← **Commit changes**.
5. من إعدادات المستودع: **Settings ← Pages ← Source: Deploy from a branch** واختار الفرع `main` والمجلد `/ (root)` ← Save.
6. خلال دقيقة-دقيقتين سيصبح الموقع متاحاً على:
   `https://USERNAME.github.io/REPO-NAME/`
7. صفحة المشرفين: `https://USERNAME.github.io/REPO-NAME/admin.html` — وفي نسخة الملف الواحد: ضيف `#/admin` في آخر الرابط.

> لا حاجة لأي خطوة بناء — الملفات ثابتة وتعمل كما هي.
> لو ظهر 404: اتأكد إن اسم الملف `index.html` بحروف صغيرة، وإن Pages متفعلة على `main` + `/ (root)`، واستنى دقيقتين.

## 💾 نظام حفظ البيانات (مهم جداً - اقرأه)

الموقع يعمل بنظامين حسب حاجتك:

### 1) الوضع المحلي (يعمل فوراً بدون أي إعداد)
- كل البيانات تُحفظ في `localStorage` متصفح الجهاز.
- مناسب للتجربة والعرض، لكن التعديلات تظهر فقط على الجهاز الذي عدّل منها.
- عند التعديل من تبويب آخر على نفس الجهاز، تتحدث بقية التبويبات فوراً.

### 2) المزامنة السحابية عبر Firebase (موصى بها للموقع الحقيقي) 🌩️
لتظهر تعديلات المشرف **فوراً لجميع الطلاب على كل الأجهزة** وليعمل إشعار «الفريق رد على سؤالك» عبر الأجهزة:

> 📘 **دليل مصوّر خطوة بخطوة مع أزرار نسخ جاهزة:** افتح ملف **`FIREBASE_SETUP.html`** في المتصفح واتبع الخطوات (5 دقائق). والملخص السريع هنا:

1. ادخل إلى [console.firebase.google.com](https://console.firebase.google.com) وأنشئ مشروعاً جديداً (مجاني).
2. من **Build ← Realtime Database** اضغط **Create Database** واختار وضع **Start in test mode** (أو الملاحظات الأمنية أدناه).
3. من **Project Settings (⚙️) ← Your apps ← Web app** أنشئ تطبيق ويب وانسخ كائن `firebaseConfig`.
4. افتح ملف `js/config.js` والصق القيم داخل `SADEEM_CONFIG.firebase.config` (أهم حقل: `databaseURL`) ثم اجعل `enabled: true`:
   ```js
   firebase: {
     enabled: true,
     config: {
       apiKey: "AIza...",
       authDomain: "project.firebaseapp.com",
       databaseURL: "https://PROJECT-default-rtdb.firebaseio.com",
       projectId: "project",
       appId: "1:123:web:abc"
     }
   },
   ```
5. ارفع التحديث على GitHub — انتهى! كل المواد والأسئلة والإعلانات ستتزامن لحظياً للجميع، وستظهر شارة خضراء «المزامنة السحابية شغالة 🌩️» في لوحة التحكم.

**قواعد أمان مقترحة لـ Realtime Database** (تبحث عن أقصى بساطة مع حماية قراءة/كتابة أساسية):

```json
{
  "rules": {
    "sadeem": {
      ".read": true,
      ".write": true
    }
  }
}
```

> تنبيه صريح: هذه القواعد تسمح لأي شخص يعرف عنوان القاعدة بالكتابة — مناسب للتجربة. للحماية الكاملة فعّل Firebase Authentication للإدارة أو ضع قواعد تحقق، لأن الموقع الثابت لا يحتوي خادماً خاصاً به. تسجيل دخول المشرفين هنا حماية واجهة (حماية العرض والإدارة) وليست حماية خادم.

## 📝 خطوات ما بعد الرفع (قائمة تحقق)

- [ ] غيّر بيانات دخول المشرفين من لوحة التحكم.
- [ ] لو رجع مجتمع الواتساب: حط رابطه من الإعدادات (رابط مجتمع أو رقم دولي بدون + مثل `201234567890`) — لو سيبته فاضي زر الواتساب يفضل مخفي.
- [ ] استبدل روابط Drive التجريبية بروابطك الحقيقية (شغّل المشاركة على «أي شخص لديه الرابط»).
- [ ] احذف السؤال التجريبي والإعلانات التجريبية وأضف إعلانك الأول.
- [ ] (اختياري) فعّل Firebase للمزامنة السحابية كما في الأعلى.
- [ ] (اختياري) احفظ نسخة JSON من بياناتك النهائية من زر التصدير.

## 🛠️ التخصيص السريع

- **الألوان والهوية**: في `css/style.css` قسم `:root` وفي إعداد Tailwind داخل `index.html` / `admin.html`.
- **الشعار**: استبدل `assets/logo.svg` (النص يعتمد على الملفين `index.html` و`admin.html`).
- **أنواع الملفات**: أضف النوع الجديد في `TYPE_STYLE` داخل `js/main.js` و`js/admin.js` وفي قائمة `types` بنافذة إضافة الملف.
- **ردود البوت الجاهزة والنوايا**: في `js/chatbot.js` (قوائم الكلمات المفتاحية `INTENTS` وأسئلة الاقتراحات `QUICK`).
- **مجتمع الواتساب**: الرابط من لوحة التحكم ← الإعدادات أو `settings.whatsapp` في `js/data.js` — يقبل رابط مجتمع/قناة أو رقم دولي، ولو فاضي كل أزرار المجتمع تختفي.
